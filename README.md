# Minecraft: End Ores

End Ores is a mod for Minecraft made by NoidDEV for PIXL. It adds plentiful
surface End Ore, smeltable End Ingots, and a set of powerful tools.
## Features

- Find frequent End Ore clusters directly on exposed End Stone, including the central island.
- Find small purpur houses on End islands, with a chest using End City treasure loot.
- Use `/locate structure minecraftendores:end_ore_house` to find a purpur house.
- Find 2-6 End Ingots in End City treasure chests and purpur-house chests.
- Mine it with a diamond-tier pickaxe and smelt it into End Ingots.
- Upgrade iron tools into End tools using a smithing table.
- Enchant End tools with the normal enchantments for their tool type.
- Explore tools with improved mining speed and bonus damage against mobs in the End.

## Compatibility

- Minecraft 1.21.1
- NeoForge 21.1.262
- Java 21

## Build it yourself

1. Install a Java 21 JDK.
2. Clone or download this repository.
3. From the project folder, run:

   ```powershell
   .\gradlew.bat build
   ```

4. Find the built mod jar in `build/libs/`.

To launch the development client instead, run:

```powershell
.\gradlew.bat runClient
```

## Modrinth

Upload the built jar from `build/libs/` as a NeoForge file for Minecraft 1.21.1.
