# Minecraft: End Ores

Lorem ipsum dolor sit amet, consectetur adipiscing elit. End Ores brings rare
End ore, smeltable End Ingots, and a set of powerful tools to Minecraft.

## Features

- Find rare End Ore in the End.
- Mine it with a diamond-tier pickaxe and smelt it into End Ingots.
- Upgrade iron tools into End tools using a smithing table.
- Explore tools with improved mining speed and bonus damage against mobs in the End.

## Compatibility

- Minecraft 1.21.1
- NeoForge 21.1.262
- Java 21

## Build it yourself

1. Install a Java 21 JDK.
2. Clone or download this repository.
3. From the project folder, run:

   ```powershell
   .\gradlew.bat build
   ```

4. Find the built mod jar in `build/libs/`.

To launch the development client instead, run:

```powershell
.\gradlew.bat runClient
```

## Modrinth

Upload the built jar from `build/libs/` as a NeoForge file for Minecraft 1.21.1.
The jar is built locally; publishing it to Modrinth requires uploading it to
your project there.
